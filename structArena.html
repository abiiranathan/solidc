Detailed Description

Arena control structure.

The hot-path state lives at the front of Arena so reset and allocation touch only this resident cache line: curr, end, head_base, current_block, and head are kept together. aligned_alloc_xp(64, sizeof(Arena)) in arena_create() keeps the heap-allocated instance aligned to a 64-byte boundary so the fast path stays in a single cache-line fetch.
