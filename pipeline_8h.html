void execute_pipeline ( CommandNode * head,
int output_fd )

Execute a pipeline of commands.

Parameters
headPointer to the first CommandNode in the pipeline.
output_fdOptional file descriptor to capture the output of the last command. If -1, the output is not redirected.

Execute a pipeline of commands.

Each stage is launched with posix_spawn(); stdin/stdout are wired between consecutive stages through anonymous pipes via posix_spawn_file_actions_t, and the final stage's stdout is redirected to output_fd when given. On a mid-pipeline failure, stages already spawned are waited on before returning so they aren't orphaned.

Parameters
headPointer to the first CommandNode in the pipeline.
output_fdFile descriptor the last stage's stdout is redirected to, or -1 to leave it inherited from the caller.
