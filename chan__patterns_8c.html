ChanStatus chan_merge ( Channel *  dest,
Channel **  sources,
size_t  count 
)

Merges count source channels into one destination channel.

A background forwarder thread moves every value from the sources to dest until all sources are closed, then closes dest. This is the latency-friendly alternative to polling with chan_select().

Parameters
destDestination channel (created by the caller).
sourcesArray of source channels (not NULL).
countNumber of sources (1..CHAN_SELECT_MAX).
Returns
CHAN_OK, CHAN_INVALID on bad args, or CHAN_NOMEM if the forwarder thread could not start.
Note
dest must remain valid until it is closed by the merger (i.e. until all sources are closed). Free the sources only after dest reports CHAN_CLOSED.

◆ chan_select()

int chan_select ( Channel **  channels,
void **  outs,
size_t  count,
int  timeout_ms 
)

Waits until one of count channels holds a value, then receives it.

Channels are polled in priority order (index 0 first) with a bounded internal wait, so a lower-index channel that receives around the same time as a higher-index one wins the race. Returns CHAN_SELECT_TIMEOUT if no channel delivers within timeout_ms. A closed-and-drained channel is skipped; if every channel is closed and drained, returns CHAN_SELECT_TIMEOUT (callers typically treat that as termination).

Parameters
channelsArray of Channel pointers.
outsParallel array of receive destinations (may be NULL to discard the received value of the winning channel).
countNumber of channels (1..CHAN_SELECT_MAX).
timeout_msTotal wait budget in milliseconds; < 0 waits forever.
Returns
Index of the channel whose value was received into outs[i] (0..count-1), or CHAN_SELECT_TIMEOUT.
Note
Values arriving on non-winning channels stay buffered.
