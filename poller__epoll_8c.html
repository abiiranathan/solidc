Detailed Description

Linux epoll backend for poller.h.

The kernel stores only the raw fd (ev.data.fd); the user pointer lives in the registration table and is resolved at wait time. This keeps internal table memory invisible to epoll, so growing or rehashing the table can never invalidate pointers the kernel holds.
