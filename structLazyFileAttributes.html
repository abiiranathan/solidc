Detailed Description

Lazy file attributes for dir_walkx.

On Linux, d_type from getdents64 is used to determine file type without stat. Size/mtime are fetched lazily via fstatat only when actually needed by the callback. This can save 90% of stat calls when the callback only checks is_dir/is_file.

Valid only during the callback invocation. Do not store the pointer.
