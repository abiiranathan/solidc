Detailed Description

String stream internal state structure with SSO support.

Note
This layout is exposed for sizing/allocation purposes only. Treat all fields as private; use the string_stream_* API to read or mutate stream contents. When size is small enough to fit inline_buf, data points into inline_buf rather than a heap allocation.
