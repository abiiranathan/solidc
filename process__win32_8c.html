Detailed Description

Win32 implementation of the process management backends: CreateProcess-based spawning with MSDN-safe command-line escaping, overlapped-I/O pipes with timeouts, and handle-based waiting.

NOTE: This file is only compiled for _WIN32 targets and cannot be built on POSIX machines; keep it in sync with process_internal.h.
