Detailed Description

POSIX (Linux/macOS/BSD) implementation of the filepath backends.

Contains all POSIX-specific filesystem primitives: opendir/readdir based directory access, stat-based attribute mapping, and — on Linux — an optimized getdents64 + openat + fstatat fast path for directory walks.
